# Innominds Copilot Enablement - Customer Cheat Sheets

This folder contains day-wise cheat sheets that can be shared with customer teams.

## Contents
- Day 1: GitHub Platform Overview
- Day 2: Copilot for Developers
- Day 3: Context Setting and Advanced Prompting
- Day 4: Build, Design, and Modernization
- Day 5: Quality, Security, and Optimization

Each cheat sheet includes:
- Helper prompts (quick copy-paste prompts)
- Reusable prompts (template prompts with placeholders)
- Custom agent samples used in the workshop (or explicit note if not used)

## How to use
1. Start with helper prompts during live work.
2. Convert repeated prompts into reusable templates for your team.
3. Use custom agents for role-specific workflows and standards enforcement.
