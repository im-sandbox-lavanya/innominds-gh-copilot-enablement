Prompt Engineering &
Practical Use Cases

Crafting effective prompts, context-setting strategies, and iterative refinement techniques

Prompt Engineering Strategies

Start General → Get Specific

Begin with the broad goal, then layer in requirements and constraints

Provide Examples

Show sample inputs/outputs; unit tests serve as executable examples

Decompose Complex Tasks

Break large requests into sequential smaller prompts for better accuracy

Eliminate Ambiguity

Name functions explicitly, specify libraries, avoid vague references like "this"

Reference Relevant Code

Use #file, #codebase, open relevant files as context

Iterate & Refine

Reference previous responses, delete failed attempts, use threads for new tasks

Practical Prompt Patterns

Weak Prompts

  • "Fix this code"
  • "Add a function to handle data"
  • "Make this better"
  • "Write tests"

Effective Prompts

  • "Fix the null pointer in parseUser() when email is missing"
  • "Add a validateOrder() function using Zod schema for #file:types.ts"
  • "Refactor to reduce cyclomatic complexity below 10 using early returns"
  • "Write Jest tests for the edge cases in #file:auth.service.ts"

Pro Tip

Use .github/copilot-instructions.md to set project-wide conventions so Copilot follows your coding standards automatically in every prompt.

Agent Mode AGENT

Local Agent

Interactive in VS Code with full workspace access

  • Edits multiple files autonomously
  • Runs terminal commands (with approval)
  • Self-corrects on build/test failures
  • Uses workspace tools & MCP servers

CLI / Background

Autonomous execution on your machine

  • Runs asynchronously in background
  • Uses Git worktrees for isolation
  • Ideal for large-scale changes
  • Checkpoints for safe rollback

Cloud Agent

Remote execution via GitHub

  • Creates branches automatically
  • Implements code & opens PRs
  • Team collaboration via reviews
  • Accessible from GitHub.com

Agent Workflow

Goal → Break into steps → Edit files → Run commands → Self-correct on failure → Task complete. Agents automatically use 7+ built-in tools to search, analyze, and modify your codebase.

Choosing the Right Mode

Capability Plan Agent Ask
Edits files — ✓ Multi-file —
Runs terminal commands — ✓ With approval —
Creates implementation plan ✓ Primary purpose ✓ Implicit —
Self-corrects on errors — ✓ Automatic —
Searches workspace ✓ ✓ ✓
Best for Planning & strategy Building & implementing Learning & exploring

Permission Levels

Default: Safe tools auto-approved, others need confirmation  |  Bypass: Auto-approves all  |  Autopilot (Preview): Fully autonomous until task completion

Plan Before Build

Plan mode for strategy, Agent mode for execution. Let Copilot analyze your codebase before making changes.

Full Lifecycle Support

Requirements → design → code → test → deploy. Copilot assists at every stage of the development lifecycle.

Modernization at Scale
